# PokeJam Shot Arc Simulator

An interactive 3D shot arc simulator with live angle, power and make % gauges. It is grounded in PokeJam's real shot code. See [REAL_NUMBERS.md](REAL_NUMBERS.md) for which numbers come from the game and which are guessed.

Open `index.html` in a browser. It is a single offline page.
